# Wexa Fabric Playwright Framework

This repository contains the initial Playwright and TypeScript framework structure. It follows the Page Object Model and separates test suites, page objects, fixtures, data, utilities, constants, and helpers.

No business-specific tests are included in this initial scaffold.

## Getting started

1. Run `npm install`.
2. Copy `.env.example` to `.env` and set `BASE_URL`.
3. Add page objects and tests in the appropriate folders as the framework evolves.
